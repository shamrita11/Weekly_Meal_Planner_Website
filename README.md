# Weekly Meal Planner
A website that intends to orgainzie recipes and create a weekly meal plan

## Create your own database
1. Open terminal in your computer and go to the cloned packages
2. Use following commands to initialize your database
    - `sqlite3 mydatabase.db`
    - `.read ./db/ddl.txt`
    - (Optionally) You may want a sample recipe `.read ./db/sample_recipe_data.txt`
